# 其他

唯一使用中文命名的目录，放**不参与运行/发布**的开发资料。子目录仍用英文：

| 目录 | 内容 |
| --- | --- |
| `reference/` | 参考项目（airi / upstream / research / extract / clone-airi-tmp / px），原样保留，不再维护 |
| `tests/` | 离线测试与假舞台；`run-all.mjs` 是总入口 |
| `tools/` | 技术探针与日志读取工具；`probes/` 是 0.5 的实测脚本，路径未跟随后续结构 |
| `notes/` | 历史过程文档与计划书（英文名） |

运行所需的一切在 `main/` 与 `plugins/`；这里删掉不影响桌宠启动。

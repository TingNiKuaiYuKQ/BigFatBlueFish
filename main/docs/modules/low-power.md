# low-power 模块（省电模式）

目录：`main/modules/low-power/`

| 文件 | 职责 |
| --- | --- |
| `lowinterrupt.mjs` | 纯状态机：进入/退出/幂等/自动模式去抖/手动覆盖 |
| `observer.ps1` | 常驻隐藏 PowerShell，每 2s 输出一行前台窗口 JSON |

## 效果

进入时保存 `{opacity, fpsCap}`，然后：
- `win.setOpacity(0.5)`（实测精确 50%）
- `bubbleWin.setOpacity(0.5)`（气泡是独立窗口，不跟主窗口走；新建的气泡也按当前状态初始化）
- 帧率降到 24
- 驾驶员事件一律丢弃（主动说话固定 0%，`user-input` 例外），不写 outbox
- **行为状态机照常运行**：眨眼、东张西望这类 1 档小动作不停 —— 省电要的是「安静」，不是「定格」

退出时恢复保存值。状态只在内存里，**不跨重启**。

> 历史：0.5.7 曾经在这里 `behavior.stop()`，结果省电时角色站着不动、也不眨眼，看着像卡死。
> 现在只靠降帧（24）和省电的透明度来省电，小动作本来就稀疏（每小时几十次），代价可以忽略。

## 自动全屏

判据：`visible && 覆盖屏幕 && !IsZoomed`。只看矩形覆盖会把最大化窗口误判成全屏；桌面/任务栏/桌宠自身 pid 也要排除。连续 3s 才进入；全屏结束立即退出；用户手动退出后本次全屏不再自动进入。

手动入口：右键菜单 → 其他 → 省电模式；托盘左键切换。
退出：左键单击桌宠；右键短按也退出，但省电时右键不弹菜单。

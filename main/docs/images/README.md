# 教程配图

教程窗口（`main/modules/tutorial/tutorial.html`）里的图都从 `/docs/images/*` 同源加载，
这个目录就是教程图的**唯一来源**。文件名不要带空格和中文，避免 URL 编码问题。

## 现在有什么

| 文件 | 类型 | 用在哪 |
| --- | --- | --- |
| `01-menu-tree.svg` | 手绘示意图 | §0 / §3 右键菜单三级结构 |
| `02-gesture.svg` | 手绘示意图 | §2 三种手势各干什么 |
| `03-bind-flow.svg` | 手绘示意图 | §4 绑定三步 + 输入胶囊三态 |
| `04-state-map.svg` | 手绘示意图 | §5 会话状态 → 表情映射 |

示意图是矢量、可直接入仓、不含任何个人信息。**真机截图留到做演示视频时一起拍**
（见 `v1.0计划书.md` §6），拍完全部缩到 **960 宽**再放进这里。


## 规矩

- 图里**不能出现**真实用户名、盘符、会话标题、聊天内容、token。
- 单张 ≤ 400 KB；PNG 用 `pngquant --quality 70-90` 压一遍，或者存成 WebP。
- 宽高比尽量 3:2 或 16:10；教程窗口正文最宽约 560 px，宽图缩下来才不糊。
- 新增图记得同步更新本文件的表格。

# UI 设计

> BigFatBlueFish 桌宠的视觉与交互设计语言。
> 基线：stage 0.6.0。本文只描述设计，不包含代码实现；数值是设计规格，用来保证后续新增界面不跑偏。

---

## 1. 一句话

**一只住在桌面上的蓝色小鱼，用「白色胶囊 + 淡蓝四角星」说话、互动和设置自己。**

设计不追求“应用感”，追求**贴纸感 / 漂浮感**：没有窗口边框、没有标题栏、没有厚重阴影；所有东西都像从人物身边轻轻长出来。

### 关键词

| 关键词 | 含义 |
| --- | --- |
| 轻盈 | 透明底、细边、无外投影，界面不抢人物 |
| 胶囊 | 几乎所有可点/可读元素都是圆角胶囊 |
| 星纹 | 四角星是唯一母题，既是底纹也是控件 |
| 蓝白 | 白底 + 淡蓝底纹 + 中蓝描边 + 深蓝文字 |
| 鱼鳞 | 多级菜单像鱼鳞一样层叠、偏移、露出边缘 |
| 克制 | 动效短、颜色少、图标少、文字短 |
| 稳定 | 界面尺寸不跳，内容在固定容器里变化 |

## 2. 五个视觉母题

### 2.1 四角星（唯一图标母题）

- 形状：四个尖角、边缘内凹的星芒，不是五角星。
- 两种用法：
  1. **底纹**：两枚星对角排列成一格，平铺；浅蓝、低透明度，只提供质感，不抢内容。
  2. **控件**：复选框的选中态、滑块拖拽头、菜单/设置里的星形装饰点。
- 规则：不引入第二套图标体系；需要“确认/选中/重要”时优先用四角星，而不是对勾、圆点或 emoji。

### 2.2 胶囊（唯一形状母题）

- 所有按钮、标签、输入框、页签、会话行、提示条都是胶囊。
- 胶囊通常是**透明填充 + 2px 内描边**，不是实心色块；底纹从胶囊内部透过去，图案连续。
- 只有“主操作”才允许实心蓝底（例如教程页的主按钮），其余保持描边式。
- 胶囊不叠胶囊：星形控件在胶囊外，文字标签在胶囊内，职责分开。

### 2.3 鱼鳞层叠

- 右键菜单的二级/三级不是“替换上一页”，而是**新一层向屏幕可用一侧偏移 22px**，盖在上一层上。
- 被盖住的层不消失、不淡出，只失去鼠标交互；露出的 22px 边缘就是“鱼鳞”。
- 层级越深，偏移越大；返回时逐层收回。
- 设计意图：让用户始终知道“我在第几层、从哪儿来”，同时避免整页切换的闪烁。

### 2.4 白色 + 淡蓝

- 主背景永远接近白；蓝色只用于**描边、文字、底纹和少量强调**。
- 不使用大块蓝色填充、渐变背景、玻璃拟态或彩色阴影。
- 蓝色分三层：淡蓝底纹（最浅）、中蓝描边（中间）、深蓝文字（最重）。

### 2.5 贴纸式悬浮

- 没有窗口外框、标题栏、关闭按钮（菜单/气泡）；关闭通过失焦、点空白、返回或菜单项完成。
- 不使用外投影去“托起”窗口；透明窗口上外投影会露出方形底，改用内描边和极淡内阴影表达层次。
- 元素之间靠**留白和偏移**分层，不靠阴影和模糊。

## 3. 色彩系统

### 3.1 基础四色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 背景白 | `#FFFFFF` | 菜单、设置页、胶囊底 |
| 底纹淡蓝 | `#E6EFFF` | 星纹、极浅背景 |
| 描边蓝 | `#5686FE` | 边框、选中态、主按钮 |
| 文字深蓝 | `#2F5AA8` | 正文、标题、标签 |

> 文字色不单独开放设置，跟随描边蓝的色系；主题色只改“背景 / 底纹 / 边框”三项。

### 3.2 透明与半透明层级

| 表面 | 底色 | 星纹 | 描边 |
| --- | --- | --- | --- |
| 气泡 | 极浅蓝，约 96% 不透明 | 中蓝星，约 42% | 中蓝，约 55%，2px |
| 右键菜单 | 白，约 97% 不透明 | 中蓝星，约 50% | 中蓝，约 90%，2px + 柔光 |
| 设置页 | 白，实色 | 淡蓝星，实色 | 中蓝，2px 实边 |
| 教程页 | 近白蓝 `#F6F8FF`，实色 | 无 | 分隔线，低透明蓝 |

### 3.3 语义色

| 语义 | 表现 |
| --- | --- |
| 选中 / 主操作 | 描边加粗到 3px，或实心蓝底 + 白字 |
| 悬停 | 描边从 55% 提升到 100% |
| 禁用 | 描边降到灰蓝，文字透明度降到约 45% |
| 错误提示 | 深色底 + 浅红文字 + 红色细边（只在舞台错误提示里出现） |
| 编辑提示 | 深蓝黑半透明胶囊 + 白字 |
| 未打开 / 次要 | 文字透明度约 62%，标签约 38% |

### 3.4 主题化规则

- 主题色只改：背景、底纹、边框；文字保持同色系深蓝。
- 所有半透明变体由边框色派生（强 / 中 / 弱三档），不散落写死颜色。
- 底纹颜色必须可被主题色驱动，不能把颜色写死在星纹图形里。

## 4. 材质与光

### 4.1 三档“能量”

| 层级 | 表面 | 视觉能量 |
| --- | --- | --- |
| 人物 | 舞台 | 最高：彩色模型、透明底、无任何界面装饰 |
| 操作 | 菜单 | 高：白底、强描边、轻柔光 |
| 阅读 | 设置 | 中：白底、细描边、星纹更密 |
| 辅助 | 气泡 | 低：淡蓝底、弱描边、无阴影 |
| 文档 | 教程 | 最低：实色、无星纹、无装饰 |

### 4.2 光的使用

- 菜单允许**极淡的内发光**（蓝色），让胶囊像微微发亮；设置页刻意减弱，避免大窗口糊成一片。
- 气泡只用**沿轮廓的投影**，不用盒子投影；投影必须跟随“气泡 + 尾巴”的整体形状。
- 透明窗口上不使用外阴影；需要层次时用描边粗细、颜色和偏移。
- 选中态不靠发光，靠**边框加粗 + 轻微上浮**。

### 4.3 星纹密度

| 场景 | 星纹格距 | 视觉密度 |
| --- | --- | --- |
| 菜单 / 气泡 | 26px | 疏，像纸上的暗纹 |
| 设置页 | 30px | 略密，填充大窗口的空白 |
| 教程页 | 无 | 保证长文阅读 |

## 5. 几何与尺寸

### 5.1 圆角

| 元素 | 圆角 |
| --- | --- |
| 胶囊按钮 / 标签 / 输入框 | 全圆角（高度的一半，视觉上 999） |
| 设置页主体卡片 | 28px |
| 会话行 | 23px（46px 高的一半） |
| 编辑虚线框 | 18px |
| 教程代码块 | 12px |
| 教程引用块 | 0 / 10 / 10 / 0（左侧直角） |

### 5.2 关键尺寸

| 元素 | 规格 |
| --- | --- |
| 菜单胶囊（收起） | 84 × 84，完整展开宽 330 |
| 菜单输入胶囊 | 660 × 168 |
| 菜单行距 | 15px |
| 菜单层偏移 | 22px / 层 |
| 菜单窗口 | 宽 696；高按行数一次算死（5 行约 699） |
| 气泡 | 最大宽 420，最小高 84，内边距 10 × 30 |
| 气泡尾巴 | 宽 28、高 16，尖端直线收 |
| 设置页 | 屏幕工作区的 70% |
| 设置行最大宽 | 880，居中 |
| 设置行内边距 | 19px 上下 |
| 会话行 | 高 46，圆角 23，最大列表高 348 |
| 表单输入 | 圆角 14，内边距 8 × 14 |
| 教程导航 | 宽 200 |
| 编辑框内缩 | 6px |
| 长按扫描指示器 | 76 × 76 |
| 托盘图标 | 32 × 32 |

### 5.3 间距节奏

常用间距：**8 / 14 / 15 / 18 / 22 / 26 / 36**。

- 小间隙（8–15）：列表项之间、标签与控件之间。
- 中间隙（18–22）：行内左右、卡片内边距。
- 大间隙（26–36）：页面边缘、区块之间。
- 不使用 4px 网格的密集排布；界面要“松”，给人物和桌面留呼吸。

### 5.4 边框

- 常规描边：2px。
- 选中态：3px。
- 设置行分隔：3px 虚线，透明度很低。
- 编辑框：2px 虚线。
- 所有描边都是**内描边**，不改变元素外尺寸。

## 6. 字体与排版

### 6.1 字体

- 系统 UI 字体：`system-ui` / `Segoe UI` / `Microsoft YaHei`。
- 不引入自定义字体；不混用衬线体。
- 中文为主，英文缩写保持大写（DSH、Qoder、UI）。

### 6.2 字号阶梯

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 菜单胶囊文字 | 30 | 600 |
| 气泡文字 | 22 | 600 |
| 设置页页签 | 17 | 600 |
| 设置页标题 / 字段标签 | 15 | 600 |
| 设置页正文 / 列表 | 14–15 | 400–600 |
| 按钮 / 小标签 | 12.5–14 | 600 |
| 会话行 | 14 | 600 |
| 教程正文 | 14 | 400 |
| 教程 H2 | 17 | 700 |
| 代码 | 12.5 | 400，等宽 |
| 辅助说明 | 11–12 | 400–600 |

### 6.3 排版规则

- 菜单/按钮文字**单行不折行**；过长省略，不压缩、不竖排。
- 标题类胶囊右对齐，正文胶囊左对齐；两者都用“单侧渐隐”暗示内容可能继续。
- 数字用等宽数字（tabular），避免滑块值、色值跳动。
- 行高：菜单 1.35–1.45；设置 1.35；教程 1.75。
- 字间距轻微增加（0.3–0.6），让胶囊里的短词更稳。

## 7. 布局

### 7.1 舞台

- 人物是唯一主体；窗口透明、无边框、不可缩放（尺寸由配置决定）。
- 气泡贴在人物头顶，水平中心对准模型，而不是窗口中心。
- 提示条放左上角，避免与头顶气泡和人物脸部冲突。
- 编辑模式的虚线框贴着窗口内缩 6px，圆角 18，和胶囊语言一致。

### 7.2 右键菜单

- 菜单贴着**模型边缘**出现，不贴窗口边缘；优先右侧，放不下换左侧，再夹回屏幕。
- 输入胶囊永远固定在菜单最底部，任何层级都不变。
- 深层固定一颗「返回」，占原本「做点什么……」的位置。
- 列表超过 4 行时内部滚动，窗口高度不变；滚动条隐藏，用上下渐隐提示。
- 层级切换只改变“显示哪些胶囊”，不改变窗口尺寸——这是避免闪烁的核心规则。

### 7.3 设置页

- 全窗口圆角卡片，占屏幕工作区 70%，居中。
- 页签居中；内容行最大宽 880，左右留白。
- 左侧字段名（190px）与右侧控件形成稳定的两栏节奏；长文本用胶囊标签。
- 行与行之间用低透明虚线分隔，不用实线卡片。
- 会话列表限制高度，露出下一项的一小截，提示可滚动。

### 7.4 教程页

- 不透明窗口，有系统边框，可缩放、可最小化。
- 左导航 200px，右侧长文；导航无滚动条，正文细滚动条。
- 标题、代码块、引用块用极浅蓝底和细边，保持“同一套蓝色”，但不使用星纹。

## 8. 动效

### 8.1 时间

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| 菜单胶囊“浮现” | 100ms | 自定义弹性缓动 |
| 菜单胶囊“抽出” | 260ms | 同上 |
| 长列表错峰 | 70ms/项，总错峰封顶约 420ms | — |
| 气泡淡入淡出 | 150–160ms | ease |
| 设置页签切换 | 160ms | ease |
| 设置面板切换 | 200ms | ease |
| 复选框星形缩放 | 140ms | 弹性缓动 |
| 编辑框出现 | 140ms | ease-out |
| 编辑提示停留 | 2.6s 后淡出 | ease |
| 「表情和姿势」自动收场 | 8s 无操作 | — |

### 8.2 动效原则

- **短、轻、快**：不做过场动画，不做大面积位移。
- 菜单是“抽屉/鱼鳞”，不是“弹窗”：从下往上逐颗出现，收起反向。
- 缩放/展开不改变窗口尺寸；只改内容显隐，避免 DWM 重新合成导致闪烁。
- 气泡必须先完成尺寸测量再淡入，避免窗口先大后小。
- 低电量模式降低帧率但保留呼吸和眨眼；动效宁可少，不要卡。

## 9. 交互状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | 2px 中蓝描边，透明底 |
| 悬停 | 描边变实、变亮；背景只加极淡蓝（约 12%） |
| 按下 | 整体缩小到约 0.94–0.96，回弹 |
| 选中 | 边框 3px，或实心蓝底白字；星形从空心变实心 |
| 禁用 | 描边灰蓝，文字约 45% 透明度，不响应悬停 |
| 被覆盖层 | 保留显示但不可点；露出的边缘可吞掉点击 |
| 未打开会话 | 标题 62% 透明度 + 小号「未打开」标签 |
| 编辑模式 | 2px 蓝色虚线圆角框 + 左上角深色胶囊提示 |
| 省电模式 | 整窗透明度 50%，帧率降低，不冒气泡 |

### 手势语言

- 左键单击：互动/退出省电；拖动：移动。
- 右键短按：打开胶囊菜单。
- 右键长按：进入位置/尺寸编辑；指针周围出现 76px 的放射状扫描指示器。
- 输入胶囊：唯一的文本入口，任何层级都不移动。

## 10. 文案与语气

- **短句、口语、角色化**：`做点什么……`、`退下吧`、`别戳我啦`、`我在这儿呢`。
- 系统状态用直白词：`未绑定驾驶员`、`驾驶员离线`、`未打开`、`省电模式`。
- 技术名词保持原样：`DSH`、`Qoder`、`fps`、`exec`、`powershell`。
- 不在按钮里写长句；不在气泡里写超过 60 字的说明。
- 不卖萌到影响理解：设置页的解释文字保持中性、可执行。
- 省略号用中文全角……，破折号用——；状态文案不用感叹号堆情绪。

## 11. 图标与符号

- 四角星：选中、滑块头、装饰。
- `✓`：只用于“已绑定”前缀。
- `⟳`：刷新。
- `＋`：新建。
- `✕`：关闭。
- 托盘图标：32×32 的蓝色小鱼（圆身、浅色肚皮、两只眼、尾巴三角），透明底，16px 缩放下仍可辨认。
- 不使用彩色 emoji 作为主要控件；不使用第三方图标库。

## 12. 场景规格速查

### 12.1 舞台

- 透明、无边框、不可缩放、置顶、可拖拽。
- 模型 2.053:1，按窗口高度铺满；左右留白由宽度决定。
- 编辑模式：虚线框 + 拖拽/缩放；非编辑状态无任何框线。

### 12.2 气泡

- 淡蓝胶囊、白蓝星纹、蓝色细边、下置三角尾巴。
- 最大宽 420，文字最多约 60 字；不接收鼠标。
- 位置贴人物头顶，尾巴随人物中心横向移动；被屏幕边缘夹住时尾巴仍指向人物。

### 12.3 右键菜单

- 白色胶囊、蓝色 2px 边、轻内发光、26px 星纹。
- 一级：一颗「做点什么……」+ 输入胶囊。
- 二级：分类列表；三级：具体项；深层固定「返回」。
- 输入胶囊永远在底部；菜单高度按最大层一次算死。
- 「表情和姿势」8 秒无选择自动收场。

### 12.4 设置页

- 70% 工作区、28px 圆角、2px 实边、30px 星纹。
- 三页签：外观 / 行为 / 指令。
- 外观：界面尺寸滑块、帧率三档（30 / 60 / 无限制）、三主题色。
- 行为：绑定 DSH 对话、主动说话与频率、开机自启、省电模式。
- 指令：左列表 + 右表单；表单输入、开关胶囊、保存/试运行/删除。
- 反馈用底部胶囊 toast，不用弹窗。

### 12.5 教程

- 不透明、可缩放、系统边框。
- 左导航 + 右长文；标题、代码、引用保持蓝白体系。
- 阅读优先：无星纹、无动效、无装饰性边框。

## 13. 设计规则（新增界面时必须遵守）

### 必须

1. 先问“它属于哪一层”：人物 / 操作 / 设置 / 阅读 / 辅助。
2. 可点元素优先做成胶囊；需要图标时先用四角星。
3. 只用四色体系；新增颜色必须先证明现有四色无法表达。
4. 选中态用边框加粗或实心主色，不用发光。
5. 透明窗口上不用外阴影；用内描边和偏移做层次。
6. 文字单行优先；长列表滚动 + 渐隐，不压缩字。
7. 动效不超过 300ms（除自动收场/长动画），不改变窗口尺寸。
8. 保持“人物优先”：任何界面都不能挡住角色脸部和主要动作。
9. 设置项左标签右控件，最大宽 880；新增行沿用虚线分隔。
10. 文案短、直白、角色化；系统状态用明确词。

### 不要

- 不要用五角星、圆点、对勾作为主图标。
- 不要用彩色渐变、玻璃模糊、厚投影、外发光堆叠。
- 不要把胶囊套胶囊，或让星形被边框挤压。
- 不要在透明窗口上使用盒子外阴影。
- 不要让菜单/设置展开时改变窗口尺寸。
- 不要把长文本塞进按钮或胶囊标题。
- 不要用 emoji 代替图标体系。
- 不要把设置页做成“表单海洋”；一页只保留必要项。

## 15. 一句话验收

把任意一张新界面放到桌面上，如果它**像一张白色贴纸、边缘是一圈细蓝线、底纹是淡淡的四角星、文字是深蓝色短句、出现和消失都不改变窗口大小**，它就属于这套设计。
